# Sack Serv
Group 5

## Linux (Debian/Ubuntu)
1. [Install Git](https://git-scm.com/downloads)
2. Clone this repository
   ```
   git clone https://github.com/daedru024/sack-serv.git
   ```
3. Change directory
   ```
   cd sack-serv
   ```
4. Execute
   ```
   ./server.sh
   ```

## macOS
1. [Install Brew](https://brew.sh)
2. Install Git
   ```
   brew install git
   ```
3. Clone this repository
   ```
   git clone https://github.com/daedru024/sack-serv.git
   ```
4. Change directory
   ```
   cd sack-serv
   ```
5. Execute
   ```
   ./server.sh
   ```

## Windows

1. [Install Git](https://git-scm.com/downloads)
2. Clone this repository
   ```
   git clone https://github.com/daedru024/sack-serv.git
   ```
3. Change directory
   ```
   cd sack-serv
   ```
4. Build
   ```
   cmake -B build
   cmake --build build
   ```
5. Run
   ```
   ./sackServ
   ./apServ
   ```

### Or:
Use [WSL](https://learn.microsoft.com/en-us/windows/wsl/basic-commands)
